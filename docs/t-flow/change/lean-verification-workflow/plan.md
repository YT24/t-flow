# 实施计划：精简验证工作流

## 实施任务

1. `T-01` 更新需求、设计与验证指导：控制 AC 粒度，定义后端/前端默认验证层级，禁止跨层全组合重复测试，并说明共享用例覆盖相关 AC。覆盖 `AC-01-1`、`AC-02-1`、`AC-03-1`。
2. `T-02` 更新测试模板、运行契约摘要和 README：说明套件到多 AC 的映射、逐 AC 状态与证据要求，以及精简策略不降低已确认验收。覆盖 `AC-02-1`、`AC-03-1`、`AC-04-1`。
3. `T-03` 增加静态回归断言并运行完整 `node --test tests/workflow.test.mjs`，确认指导内容、既有状态机、确认门禁、证据校验和兼容行为。覆盖 `AC-01-1`、`AC-02-1`、`AC-03-1`、`AC-04-1`、`AC-05-1`。

## 验证任务

- 静态检查修改后的 Skill、模板和 README 均包含已确认的精简验证规则，不残留与之冲突的旧指导。
- 使用现有 Node 测试套件执行真实回归；失败时修复后重跑，不复用旧通过结果。
- 本变更无手工页面、数据库、真实浏览器或负向业务权限验收项；`AC-05-1` 的兼容行为由现有自动化回归验证。

## 边界

不修改 `workflow-protocol.json`、运行脚本、证据 schema 或历史变更产物；任务完成不等于交付验收完成。
