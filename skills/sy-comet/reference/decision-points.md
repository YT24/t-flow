# 用户决策

澄清完成确认目标与范围；UI 原型生成后确认原型没有问题（无界面需求时用 skip ui <原因> 跳过该停顿点）；设计完成确认技术方案（小型变更——无架构调整、无数据迁移、无新接口——可 skip design 记录原因跳过）；归档前确认验收。只把实际用户确认原文写入 approve，不得代替用户批准。已确认且输入未变直接复用；缺事实自行调查，缺业务决定再问。安装依赖已获授权，不逐个询问。UI Skill 内必要业务决定沿用现有明确确认，不默认为已批准。

PRD 不单设停顿点：design 的确认指纹覆盖 specify 全部产物，PRD/ADR/spec-delta 一旦变化，design 确认自动失效并需重新确认，范围契约由此获得等价保护。

验证-修复循环超限时，向用户展示失败历史并等待方向选择（继续修复/调整需求/停止），用 decide <用户决策原文> 记录后解除。
