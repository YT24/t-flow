## 界面范围声明（机器可读，必填）

```ui-scope
mode: new
files: [src/pages/NewPage.vue]
affected: []
prototypes: []
```

- `mode`：`new`（新建界面）或 `change`（存量项目改造既有界面）
- `files`：本次交付/改动的界面文件或目录（**必须真实存在**，会被强制计入证据输入——改动它们会使证据过期）
- `affected`：`mode: change` 时**必填**，列出受影响的既有界面，供用户评估影响面与回归范围
- `prototypes`：已展示并确认的原型或截图的项目内路径，须位于 `docs/t-flow/change/<change-id>/`，且为真实文件。原型修改使 UI 确认失效；没有独立原型时写空数组并说明评审对象。

> 这是把「用户确认的界面」与「真实交付的文件」绑定的机制。此前 ui.md 只是描述，确认的是文案而非界面；声明后，若实际交付的不是这里列的文件，证据绑定与校验会暴露差异。
